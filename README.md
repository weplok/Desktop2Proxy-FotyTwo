
Access Manager — прототип (Windows 10 x64)
========================================

Описание
--------
Это учебный/административный прототип на Python + PyQt5 для управления подключениями к разным системам
(SSH, FTP и т.д). Программа выполняет простой сетевой скан (ping/tcp-connect) по локальной подсети (/24, первые 120 хостов),
определяет открытые порты и пингует их, чтобы узнать протокол и его основные характеристики.

Пререквизиты (на Windows 10 x64)
--------------------------------
1. Установленный Python 3.10+ (рекомендуется 3.10-3.12).
2. Установите зависимости:
   pip install -r requirements.txt

3. Для RDP: mstsc (входит в Windows). Для корректной передачи пароля используется cmdkey — встроенная утилита Windows.
   Приложение временно добавляет учетные данные в Credential Manager через cmdkey и удаляет их после запуска mstsc.

4. Для VNC/RDP/SSH-клиентов: рекомендуется иметь установленные внешние клиенты (TightVNC, RealVNC, PuTTY и т.д.).
   Приложение пытается вызвать программы по стандартным именам (vncviewer, mstsc, putty). Если они не установлены,
   используйте отдельный клиент.

Запуск
-----
1. Распакуйте архив в папку на машине администратора.
2. Установите зависимости: pip install -r requirements.txt
3. Запустите: python main.py

Сборка в один exe (опционально)
-------------------------------
Можно собрать exe с помощью PyInstaller:
  pip install pyinstaller
  pyinstaller --onefile --windowed main.py

Ограничения и заметки
---------------------
- Прототип определяет ОС только грубо по открытым портам. Для точного fingerprinting используйте nmap с правами администратора.
- Для интеграции nmap можно расширить сканер: запускать 'nmap -O --osscan-guess' и парсить вывод (nmap должен быть установлен).
- Программа НЕ хранит пароли постоянно. RDP-пароль передаётся в Credential Manager временно через cmdkey.
- Для production потребуется добавить:
  * Шифрованное локальное хранилище учетных данных (например, Windows DPAPI, или файл зашифрованный cryptography.Fernet)
  * Жёсткий аудит и журналирование
  * Управление правами доступа и UI для подтверждений действий администратора

Юридическое
-----------
Используйте только в сетях, где у вас есть явное разрешение администратора.
