Кейс "Desktop2Proxy" на DDoS-Guard Hackaton 2025. Команда "Фоти ту"
========================================

## Описание
***
Это учебный/административный прототип на Python + PyQt5 для управления подключениями к разным системам
(SSH, FTP и т.д). Программа выполняет простой сетевой скан (ping/tcp-connect) по локальной подсети (/24, первые 120 хостов),
определяет открытые порты и пингует их, чтобы узнать протокол и его основные характеристики.

Пользователь может подключиться к любой ОС прямо из окна программы без необходимости дополнительных настроек - нужны
только логин и пароль.

## Структура программы
***
- ```app``` – файлы QT-приложения, модуль сканирования и фингерпринта
- ```protocols``` – модули протоколов, содержащие Connection-классы (инструкции) + Handler

## Пререквизиты (на Windows 10 x64)
***
1. Установленный ```Python 3.10+``` (рекомендуется 3.10-3.12).
2. Необходимо наличие настроенного ```nmap```

## Запуск
***
1. Склонируйте репозиторий
```bash 
git clone https://github.com/weplok/Desktop2Proxy-FotyTwo.git
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите:
```bash
python app\main.py
```

## Ограничения и заметки
***
- Для production потребуется добавить:
  * Шифрованное локальное хранилище учетных данных (например, Windows DPAPI, или файл зашифрованный cryptography.Fernet)
  * Жёсткий аудит и журналирование
  * Управление правами доступа и UI для подтверждений действий администратора

## Для добавления новых протоколов
***
  * Добавление метода определения протокола в ```detect_protocol.py```
  * Добавление модуля протокола в ```protocols```
  * Создание хендлера протокола в ```protocol_handlers.py```
